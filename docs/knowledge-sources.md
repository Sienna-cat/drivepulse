## 事实、推断与适用条件

- `facts` 只保留官网可以找到的内容；`inferredAudience` 为产品分析假设。`confidence: official` 表示参考资料类型，不表示推断人群已由蔚来验证。
- 用户场景卡整体标为 `inferred`，其参考依据仍链接到相关车型官网。没有据此推断车主职业、家庭或真实兴趣。
- 无忧服务三档人群描述来自官方：轻享版为用车不多、场景简单；乐享版为多数场景；尊享版为里程较多、场景复杂。未将套餐价格作为永久报价。
- 服务卫士的官方能力是远程诊断、异常信号监测、预警与专家跟进。Demo 未连接此系统，不把它当作已经获取的真实车主记录。
- 六/七座 ES8 与大五座 ES8 的空间参数分开存放；车型官网页面可能同时包含选装和后续推送功能，以配置器、具体版本与交付为准。
- 智能辅助驾驶相关内容按官网功能介绍记录，不能替代驾驶员，不代表自动驾驶承诺。
- 首任车主道路救援、重大事故代客值守等权益存在身份、地区、套餐条件，不自动承诺给所有车主。本版不把它们作为规则引擎里的无条件权益。

## 更新方法

1. 打开上述对应官方页面，核对当前车型版本、配置、地区及权益条件。
2. 修改 `src/knowledge.js` 相应条目，保持 ID 稳定；同时更新 `sourceDate`、事实、限制说明。页面未能验证的数字删除或明确标注待核验，不猜测。
3. 将研究推断保留在 `inferredAudience`；没有真实用户证据时不更新车主档案。
4. 运行 `node --test tests/*.test.js`，并在浏览器检查分类与中文搜索。

现阶段为确定性关键词检索，供人工查阅，未自动参与运营方案生成。未来接入模型时，应返回知识条目 ID、来源、日期与事实片段，并保留人工审批。
