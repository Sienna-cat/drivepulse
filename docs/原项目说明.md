# DrivePulse · 车主运营工作台

面向「高级 AI 产品经理 — Agent 应用」岗位的个人作品集项目。可运行的 Web Demo 加作品集说明页，展示车主关怀任务从交办、数据查询、规则校验、人工审核到执行反馈的完整过程。

**当前实现是确定性规则工作流，不包含大模型调用。** 24 位车主及其业务记录均为虚构，不代表蔚来内部产品或真实业务。所有操作保存在当前浏览器，任务不会向外部渠道发送。

## 三分钟演示

1. 从工作台选择「上海」「下降 ≥50%」「正常运行」。目标自由文本记录交办背景，城市和阈值实际控制筛选；有服务需求是固定条件。
2. 初始数据返回 9 位候选、5 位可触达、4 位排除。查看来源，解释退订、投诉、信息缺失及触达间隔的取舍。
3. 修改文案、取消一位车主。可以刷新验证草稿恢复，再确认创建 4 条模拟任务。
4. 分别记录已触达、已响应、拒绝联系和转人工。「已触达」后仍可更新为「已响应」。拒绝会更新车主退订状态并影响下一次运行。
5. 打开结果复盘，解释当前样本量与指标分母。没有真实发送和真实业务结果。
6. 新建一次「查询失败」或「规则过期」任务，展示阻断、失败记录与继续执行。

任务详情右上角可导出运行记录 JSON。左下角「重置演示数据」恢复初始数据；同一次页面会话内可撤销重置。

## 功能

- 工作台：运营目标、结构化条件、三种演示场景、真实本地运行统计。
- 任务中心：状态筛选、任务切换、步骤时间线、可展开的工具返回值、审核草稿。
- 人工审核：选择车主、修改文案、再次校验资格、幂等创建任务。
- 结果回流：反馈历史、拒绝更新退订、下一步行动、统计计算。
- 车主资料：搜索、城市过滤、行为数据、服务需求与触达资格。
- 蔚来知识库：21 条带官网来源的知识卡片，覆盖 9 个车型系列 / 10 个版本、服务、补能与用户场景；支持关键词与分类组合检索，区分官方事实和人群匹配假设。
- 作品集说明：JD 映射、问题假设、产品取舍、工具契约、验证计划、面试演示顺序。
- 接续工作：浏览器保存状态、刷新恢复正在执行的步骤、失败从原步骤继续。

## 状态与边界

```text
running → awaiting_approval → approved → completed
   ↓
blocked → 从失败步骤恢复
```

`approved` 表示已经创建待执行任务。`completed` 表示该运行的每项任务都已有反馈，不等同于服务问题已经解决。已响应只提出人工确认服务时间的下一步，不直接创建预约。

记录“拒绝联系”后，退订是保守保留的状态；把某项反馈改成其他结果不会自动恢复触达授权。

指标：

- 任务响应占比 = 当前状态为已响应的任务数 / 全部已创建任务数。不是现实触达响应率。
- 反馈完成度 = 已有结果的任务数 / 全部已创建任务数。
- 工具调用成功率 = 成功本地步骤数 / 全部本地步骤数，包含模板步骤、写入与重试。
- 排除次数按每次运行累计，同一车主可能重复计数。
- 数据来自当前浏览器，不预填业务提升、留存或转化结果。
