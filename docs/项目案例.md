# DrivePulse：从运营目标到任务反馈

面向车主运营，将活跃变化、服务需求和联系资格组织为可审核的关怀任务。本人完成产品设计、交互实现、规则与状态设计，以及功能验证。

主要决策：以任务组织页面；事实与建议分开；审批前允许修改人群和文案；执行前再次核对资格；拒绝反馈影响下一次筛选。

当前交互使用 24 条示例车主记录、规则与模板，操作保存在浏览器。完整路径为筛选 → 审核 → 创建任务 → 记录反馈 → 结果复盘。
